# 管控后台模块原子功能拆解

## 一、原子功能清单

| # | 原子功能 | 说明 | 核心技术 |
|---|---------|------|---------|
| **I1** | 检索权重热调整面板 | 支持通过 UI 界面实时修改 `bm25_weight`、`vector_weight` 等参数，并持久化到数据库。 | Vue3 + JSON 配置表 |
| **I2** | 同义词库管理 | 提供同义词添加、删除、导入功能，并支持“一键应用”触发 ES 索引重建/热加载。 | ES `_reload_search_analyzers` |
| **I3** | 批量导入全局监控 | 聚合展示所有导入批次的总览看板（饼图显示成功/失败/处理中）。 | ECharts / 进度条组件 |
| **I4** | 单文档全链路追踪 | 输入 `doc_id` 查询该文档从“接入 -> 解析 -> 分片 -> 向量化 -> 入库”的完整 Trace 日志。 | MySQL 日志关联查询 |
| **I5** | 失败任务重试中心 | 自动归类死信队列中的任务, 支持“批量重试处理”或“手动修改文件后重试”。 | Kafka 任务重发逻辑 |
| **I6** | 组件监控与健康预警 | 实时探活 Python AI 服务 (显存/并发)、ES 磁盘占用、Kafka 堆积情况。 | Prometheus / 自研接口探活 |
| **I7** | 检索日志分析 (Bad Case) | 统计分析点击率低或“零结果”请求，为人工调整权重和添加同义词提供数据支持。 | MySQL 聚合分析 |
| **I8** | 文档元数据人工补录 | 对于自动提取失败的关键字段（如文号、发文日期），支持人工在界面上进行搜索与订正。 | 表单编辑 + 增量更新 |

## 二、界面功能布局建议

1. **首页 Dashboard**：展示今日搜索量、今日入库量、失败任务数、系统资源占用。
2. **检索优化页**：权重配置表单、同义词维护表格、检索效果模拟测试框。
3. **数据中心**：导入记录列表、失败文档处理工作台、文档查询与编辑入口。
4. **运维中心**：服务探活状态、日志导出、ES 索引重建入口。

## 三、核心技术选型

- **前端技术**：Vue3 + Element Plus (快速搭建政务风格管理后台)。
- **后端支持**：Java 调用 ES 给出的管理类 REST API。
- **实时性**：重要任务进度通过 Websocket 或短轮询实时更新。
