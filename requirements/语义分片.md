#	原子功能	说明	输入 → 输出
A1	文档结构识别	识别文档中的标题层级（一、(一)、1.）、段落、表格、列表等结构元素	原始文本 → 带结构标记的文本树
A2	公文标题层级解析	按政务公文层级规范解析：一级标题（一、二、）→ 二级（(一)(二)）→ 三级（1. 2.）→ 四级（(1)(2)）	文本树 → 层级节点树
A3	文号独立提取	将文号（如"国发〔2024〕1号"）提取为独立 Chunk，标记高权重	文本 → 文号Chunk + 剩余文本
A4	表格独立提取	将表格提取为独立 Chunk，保留表头作为上下文	文本 → 表格Chunk列表 + 正文文本
A5	按章节边界初切	在标题层级处强制切分，每个章节/段落作为一个初始块	层级节点树 → 初始块列表
A6	长块二次切分	初始块超过 500 字时，按句号/分号等语义断点二次切分，避免跨语义截断	超长初始块 → 多个子块
A7	短块向上合并	初始块不足 100 字时，与相邻块合并（优先向上合并到同一章节）	过短初始块 → 合并后的块
A8	重叠窗口生成	相邻 Chunk 之间添加 50 字重叠文本，保证语义连续性	Chunk列表 → 带重叠的Chunk列表
A9	纯文本滑动窗口兜底	无层级结构的纯文本，使用滑动窗口（窗口 400 字，步长 350 字）切分	无结构文本 → Chunk列表
A10	Chunk 元数据标注	为每个 Chunk 标注：类型（标题/正文/表格/文号）、所属章节、页码位置、在文档中的序号	Chunk → 带元数据的Chunk
A11	低质量 Chunk 过滤	过滤掉：纯空白、特殊字符占比>80%、字数<10（文号除外）、与相邻Chunk重复率>90% 的块	Chunk列表 → 有效Chunk列表

三、涉及的技术与工具
原子功能	Python 库/技术	实现要点
A1 结构识别	python-docx（Word）、pdfplumber（PDF）	Word 通过 paragraph.style 获取标题级别；PDF 通过字体大小/加粗推断标题
A2 标题层级	正则表达式	政务公文层级模式固定：^[一二三四五六七八九十]+、（一级）、^\([一二三]\)（二级）、^\d+\.（三级）
A3 文号提取	正则表达式	匹配模式：[\u4e00-\u9fa5]+〔\d{4}〕\d+号
A4 表格提取	python-docx（Word表格）、pdfplumber.extract_tables()（PDF表格）	表格转为 Markdown 格式或"表头:值"键值对文本
A5 章节初切	自定义逻辑	按标题节点递归拆分，每个叶子节点为一个初始块
A6 长块切分	自定义 + re.split	按中文句号。、分号；、换行符 \n 作为断点，贪心切分到 500 字以内
A7 短块合并	自定义逻辑	向上合并到同章节的前一个块，合并后仍<100字则继续向上
A8 重叠窗口	自定义逻辑	取前一个 Chunk 的末尾 50 字追加到当前 Chunk 开头
A9 滑动窗口	langchain.text_splitter.RecursiveCharacterTextSplitter 或自定义	chunk_size=400, chunk_overlap=50, separators=["\n\n", "\n", "。", "；"]
A10 元数据	自定义逻辑	标注 chunk_type（title/body/table/doc_number）、section_path（如"一、(二)"）、chunk_index
A11 质量过滤	自定义 + 正则	空白检测、特殊字符占比计算、相邻 Chunk 余弦相似度>0.95 视为重复
四、Chunk 输出数据结构
python
@dataclass
class Chunk:
    chunk_id: str          # 唯一ID, 如 "doc_1001_chunk_003"
    doc_id: str            # 关联文档ID
    content: str           # 分片文本内容（300-500字）
    chunk_type: str        # "title" | "body" | "table" | "doc_number"
    chunk_index: int       # 在文档中的顺序（0-based）
    section_path: str      # 所属章节路径，如 "一、总则/(一)适用范围"
    page_number: int       # 所在页码（PDF可精确，Word为估算）
    overlap_prev: str      # 与前一个Chunk的重叠文本
    char_count: int        # 字符数
    quality_score: float   # 质量评分（0-1），用于后续过滤
五、关键配置参数（需可配置，不写死）
参数	默认值	说明
max_chunk_size	500 字	单 Chunk 最大字数
min_chunk_size	100 字	低于此值触发合并
target_chunk_size	350 字	切分目标字数
overlap_size	50 字	相邻 Chunk 重叠字数
sliding_window_size	400 字	纯文本滑动窗口大小
sliding_window_step	350 字	滑动窗口步长
min_quality_score	0.3	低于此值过滤掉
