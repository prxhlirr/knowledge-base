# 文档处理模块原子功能拆解

## 一、原子功能清单

文档处理模块作为中间层，负责协调“解析”、“清洗”、“分片”与“向量化”四个子阶段，其核心是将原始二进制文件转化为可被索引的向量数据。

| #      | 原子功能                   | 说明                                                        | 核心技术                         |
| ------ | ---------------------- | --------------------------------------------------------- | ---------------------------- |
| **P1** | 格式预校准                  | 识别文件 MIME 类型，调用对应的解析驱动（Word/PDF/Text），处理加密/损坏文件。          | `python-magic`, `try-except` |
| **P2** | 乱码过滤与转码                | 针对内网老旧文档，自动识别 GBK/BIG5 编码并统一转码为 UTF-8，过滤非法 Unicode 字符。    | `chardet`, `ftfy`            |
| **P3** | 公文专属清洗 (Preprocessing) | 移除页眉页脚（如"机密"、页码）、多余空行、无意义特殊符号（■、★）。                       | 正则表达式规则库                     |
| **P4** | 结构化要素提取                | 自动提取公文标题、发文机关、日期、文号，作为后续元数据索引依据。                          | 模式匹配 + 布局分析                  |
| **P5** | 语义智能分片 (Chunking)      | 基于公文层级逻辑进行分片，确保每个 Chunk 语义完整。 | 详见 [语义分片.md](./语义分片.md)      |
| **P6** | 分片质量评估                 | 计算分片的统计学特征（字数分布、符号比率），拦截低质量解析结果。                          | 启发式规则                        |
| **P7** | FP16 向量化推理             | 将清洗后的文本转换为 1024 维归一化向量。                                   | 详见 [向量化模块.md](./向量化模块.md)    |
| **P8** | 任务 TraceID 绑定          | 为处理链路生成唯一追踪 ID，记录每一步的耗时与入参，供后台审计。                         | UUID / 日志上下文                 |

## 二、处理流程

```mermaid
graph TD
    A[Kafka 文档任务] --> B[P1: 格式识别与加载]
    B --> C[P2: 编码适配与清洗]
    C --> D[P4: 公文要素(文号等)提取]
    D --> E[P5: 智能分片]
    E --> F[P6: 质量评估过滤]
    F --> G[P7: BGE-m3 向量化计算]
    G --> H[P8: 组装索引包包 (Vector + Metadata)]
    H --> I[写入 ES 索引]
```

## 三、涉及的技术与工具

- **基础解析库**：`python-docx` (Word), `pdfplumber` (PDF), `pycryptodome` (处理加密文件)。
- **清洗引擎**：自定义 Regex 规则链 + `BeautifulSoup` (针对 HTML 来源)。
- **切片工具**：基于 Python 的自研结构化拆分逻辑，配合 `LangChain` 的文本分割器。
- **并发控制**：`ProcessPoolExecutor` 多进程并行解析，避免 CPU 密集型操作阻塞。

## 四、关键配置参数

| 参数                    | 默认值  | 说明                             |
| --------------------- | ---- | ------------------------------ |
| `clean.remove_header` | True | 是否移除页眉页脚                       |
| `clean.min_para_len`  | 5    | 忽略少于 5 个字的琐碎段落（标题除外）           |
| `process.timeout`     | 60s  | 单个文档处理的最大时限（防止文件过大卡死）          |
| `process.max_mem`     | 1GB  | 单进程最大内存限制，超过则自动熔断（针对超大 PDF/表格） |
