# 方案二执行计划：Query 意图分类模型（NAVIGATIONAL / INFORMATIONAL）

## 目标
用一个 2MB、推理 < 5ms 的轻量 BERT 分类模型，精准区分"精确关键词检索"和"信息探索型问句"，替换当前脆弱的正则路由，实现不受字数和词典局限的动态意图判断。

## Phase 2：数据导出与意图标注（第 3-4 周）

> **目标**：构建 2000 条带标签的训练集

### 工具
- **标注工具**：[Label Studio](https://labelstud.io)（本地 Docker 部署，离线可用）
- **导出格式**：`jsonl`，每行 `{"text": "一件事", "label": "NAVIGATIONAL"}`

### 标注规则（供标注人员参考）

| 意图类型 | 判断标准 | 示例 |
|---|---|---|
| `NAVIGATIONAL` | 纯名词/实体检索，无逻辑关系 | "一件事"、"公积金管理条例"、"劳动合同法" |
| `INFORMATIONAL` | 含疑问、逻辑、流程、条件 | "如何提取公积金"、"超期未审批怎么办"、"和行政许可的区别" |

### 数量要求
- NAVIGATIONAL：~1000 条
- INFORMATIONAL：~1000 条（可手工补充政务问句，或用 ChatGPT 生成辅助数据）

## Phase 3：模型微调与导出（第 5-6 周）

> **目标**：训练一个 < 5ms 推理、< 5MB 的文本二分类模型，导出 ONNX

### 选型：`hfl/chinese-macbert-base` 蒸馏版（推荐）
- 或直接用 `clue/albert_chinese_tiny`（更轻，仅 2MB，推理 2ms）
- 训练框架：`transformers` + `Trainer` API（纯 CPU 可运行）

### 训练脚本（新建 `ai_service/scripts/train_intent_classifier.py`）

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification, Trainer, TrainingArguments
import datasets, torch

# 加载标注数据
ds = datasets.load_dataset("json", data_files={"train": "data/intent_train.jsonl", "test": "data/intent_test.jsonl"})
tokenizer = AutoTokenizer.from_pretrained("clue/albert_chinese_tiny")
model = AutoModelForSequenceClassification.from_pretrained("clue/albert_chinese_tiny", num_labels=2)

def tokenize(batch):
    return tokenizer(batch["text"], truncation=True, max_length=64, padding="max_length")

ds = ds.map(tokenize, batched=True)
ds = ds.rename_column("label_id", "labels")

trainer = Trainer(
    model=model,
    args=TrainingArguments(output_dir="./intent_model", num_train_epochs=5, per_device_train_batch_size=32),
    train_dataset=ds["train"], eval_dataset=ds["test"]
)
trainer.train()
```

### ONNX 导出
```bash
python -m transformers.onnx --model=./intent_model --feature=sequence-classification ./intent_model_onnx/
# 量化（可选，进一步降低推理延迟）
python -m onnxruntime.tools.quantize --input intent_model_onnx/model.onnx --output intent_model_onnx/model_quant.onnx
```

### 验收指标
- 测试集 F1 ≥ 0.92
- 推理延迟（CPU）≤ 5ms/query（ONNX Runtime, batch=1）
